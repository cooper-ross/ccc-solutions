# CCC Solutions
My personal collection of C++ solutions for the Canadian Computing Competition (CCC) and Canadian Computing Olympiad (CCO) so I can practice problems and have an archive of that practice for later review, as well as track which problems I've solved!

## Contests

- `s1.cpp` - Hat Circle
- `s2.cpp` - Heavy-Light Composition
- `s3.cpp` - Swipe
- `s4.cpp` - Painting Roads
- `s5.cpp` - Chocolate Bar Partition
